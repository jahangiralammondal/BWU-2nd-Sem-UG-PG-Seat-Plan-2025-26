# BWU-2nd-Sem-UG-PG-Seat-Plan-2025-26
Exam Seat Finder is a web-based application built for students of Brainware University. It allows users to quickly retrieve their exam seating details—such as room number, building, floor, and program—by entering their roll number. The project focuses on speed, simplicity, and a clean user interface to improve the exam experience.
